# Sakura Life MVP 页面与交互流程

## 1. MVP 目标

第一版的目标不是功能大而全，而是让用户每天愿意打开、能快速打卡、能看到庭院变化。

MVP 应该满足：

- 打开应用后 5 秒内知道今天要做什么。
- 完成任务后 1 秒内看到奖励反馈。
- 状态差的时候可以用低能量模式继续行动。
- 任务、资源、庭院成长形成一个闭环。
- 手机端体验优先，桌面端自然适配。

## 2. 页面地图

第一版页面：

```text
/login              登录页
/                   今日页
/tasks              任务库
/tasks/new          新建任务
/tasks/:id/edit     编辑任务
/garden             庭院
/calendar           日历
/me                 我的
```

底部导航建议：

```text
今日 | 任务 | 庭院 | 日历 | 我的
```

手机端使用底部导航，桌面端可以使用左侧导航。

## 3. 首次使用流程

### 3.1 登录

用户访问应用：

```text
未登录 -> /login
已登录 -> /
```

登录页内容：

- Sakura Life 标题。
- 一句短文案：今天也照顾一点点。
- 用户名输入框。
- 密码输入框。
- 登录按钮。

交互规则：

- 登录成功后进入今日页。
- 登录失败显示温和错误提示，例如「账号或密码不正确」。
- 第一版不显示注册入口。
- 第一版不显示找回密码入口。

### 3.2 空状态引导

如果用户还没有任务：

今日页显示空状态：

```text
庭院还在等待今天的第一束阳光

[添加第一个任务]
```

点击后进入新建任务页。

建议提供快捷任务模板：

- 学习 30 分钟
- 健身 20 分钟
- 整理房间 10 分钟
- 早睡
- 写代码 45 分钟

用户可以直接选模板，也可以自己输入。

## 4. 今日页

路径：`/`

今日页是第一版最重要的页面。

### 4.1 页面结构

手机端从上到下：

```text
[顶部状态栏]
等级 / XP / 阳光 / 水滴 / 樱花币

[庭院主视觉]
2D 樱花庭院

[今日进度]
今天已完成 2 / 4
连续照顾 5 天

[今日任务列表]
任务卡片
任务卡片
任务卡片

[快速操作]
添加今日任务
低能量模式
今日结算
```

桌面端可以分两栏：

```text
左侧：庭院主视觉
右侧：今日任务、资源、进度
```

### 4.2 顶部状态栏

显示：

- 等级
- XP 进度
- 阳光
- 水滴
- 樱花币

原则：

- 状态栏要紧凑。
- 资源变化时有轻微动画。
- 不要占据过多垂直空间。

### 4.3 庭院主视觉

庭院区域显示：

- 当前樱花树阶段。
- 已解锁装饰。
- 今日状态。

状态示例：

- 今天还没打卡：庭院安静，光线柔和。
- 完成第一个任务：树冠亮起，花瓣飘落。
- 今日任务全部完成：庭院进入满活力状态。
- 低能量模式完成：庭院进入安稳夜灯状态。

### 4.4 今日任务卡片

任务卡片内容：

```text
任务名称
分类 / 难度
启动版目标
标准版目标
超额版目标

[启动] [完成] [超额]
```

按钮含义：

- 启动：最低完成，发放 30% 奖励。
- 完成：标准完成，发放 100% 奖励。
- 超额：超额完成，发放 150% 奖励。

完成后卡片状态：

```text
已完成：标准版
+40 XP +8 阳光 +5 樱花币
```

已完成任务默认折叠到列表下方，避免干扰未完成任务。

### 4.5 快速添加今日任务

今日页提供一个轻量入口：

```text
[+ 添加今日任务]
```

点击后打开选择面板：

- 从任务库选择。
- 临时添加任务。
- 使用快捷模板。

如果是临时任务，完成后可以选择是否保存到任务库。

## 5. 低能量模式

低能量模式是第一版的重点功能之一。

### 5.1 入口

今日页显示一个按钮：

```text
低能量模式
```

点击后弹出确认面板：

```text
今天只照顾一点点也可以。

系统会把今日目标缩小为 1 个最容易开始的任务。

[开启] [取消]
```

### 5.2 开启后变化

开启后：

- 今日目标改为完成任意 1 个启动版任务。
- 任务列表优先显示最小任务。
- 奖励变少，但连续照顾不掉。
- 庭院进入安静夜灯视觉。

### 5.3 完成后反馈

完成低能量目标后：

```text
今天已经照顾过庭院了。
不是每一天都要盛开，保留节奏也很好。
```

不要出现责备性文案。

## 6. 新建任务页

路径：`/tasks/new`

### 6.1 表单字段

字段：

- 任务名称
- 分类
- 难度
- 重复规则
- 启动版目标
- 标准版目标
- 超额版目标
- 是否今天就加入

### 6.2 分类选项

分类：

- 学习
- 健身
- 睡眠
- 生活
- 创作
- 工作
- 自定义

每个分类有默认奖励倾向：

- 学习：专注
- 健身：体能
- 睡眠：恢复
- 生活：秩序
- 创作：创造
- 工作：专注或创造
- 自定义：用户选择

### 6.3 难度选项

难度：

- 简单
- 普通
- 困难
- 史诗

建议默认选择普通。

### 6.4 重复规则

第一版支持：

- 不重复
- 每天
- 每周指定日期

复杂规则以后再做。

## 7. 任务库页

路径：`/tasks`

### 7.1 页面结构

```text
[搜索 / 分类筛选]

[任务列表]
任务名称 | 分类 | 难度 | 重复规则 | 状态
[加入今日] [编辑]

[新建任务]
```

### 7.2 任务状态

状态：

- 启用
- 暂停

暂停任务不会自动出现在今日任务推荐里，但历史记录保留。

## 8. 庭院页

路径：`/garden`

庭院页用于完整查看养成成果。

### 8.1 页面结构

```text
[完整 2D 庭院]

[樱花树等级]
阶段 / 进度 / 下阶段需要资源

[装饰栏]
已摆放 / 可摆放 / 未解锁

[商店入口]
```

### 8.2 樱花树阶段

第一版至少 6 个阶段：

1. 种子
2. 幼苗
3. 小树
4. 长叶
5. 初花
6. 满开

每个阶段都要有可见差异。

### 8.3 装饰摆放

第一版先做固定位置：

- 左前景
- 右前景
- 树下
- 水池旁
- 小路旁

用户选择装饰后，点击位置即可摆放。

如果第一版时间紧，可以先做「购买后自动显示」，拖拽摆放留到第二版。

## 9. 日历页

路径：`/calendar`

### 9.1 页面结构

```text
[月份切换]

[月历]
每天显示完成强度

[选中日期详情]
完成任务列表
获得奖励
当天一句总结
```

### 9.2 完成强度

日期颜色规则：

- 无完成：浅灰
- 启动完成：浅绿
- 标准完成：绿色
- 全部完成：粉色或金色点缀

不要使用过强烈的红色表示失败。

## 10. 我的页

路径：`/me`

### 10.1 页面结构

```text
[用户信息]
名称 / 等级 / 连续天数

[属性面板]
专注 / 体能 / 秩序 / 创造 / 恢复

[成就]
已解锁成就

[设置]
修改密码
退出登录
```

### 10.2 修改密码

第一版只允许登录后修改密码。

字段：

- 当前密码
- 新密码
- 确认新密码

规则：

- 新密码至少 8 位。
- 修改成功后保持登录，或要求重新登录都可以。

## 11. 打卡反馈流程

用户点击任务完成按钮后：

```text
点击完成
-> 前端显示 loading
-> 后端写入 CheckIn
-> 更新 Profile
-> 更新 DailyTask
-> 更新 GardenState
-> 返回奖励结果
-> 前端播放反馈动画
-> 任务卡片进入已完成状态
```

反馈内容：

- 奖励弹出。
- XP 条增长。
- 资源数字跳动。
- 庭院花瓣或光点动画。
- 如果解锁装饰或阶段，显示解锁提示。

## 12. 今日结算流程

入口：今日页的「今日结算」。

结算页或弹窗显示：

```text
今天照顾了庭院

完成任务：3 个
获得 XP：120
获得阳光：30
成长最多：专注 +4
连续照顾：5 天

[明天继续]
```

如果今天只完成启动版，也要显示正向文案：

```text
今天保住了节奏。
一点点也算数。
```

## 13. 周结算流程

第一版可以先不自动推送，只在日历或我的页提供入口。

显示：

- 本周完成天数。
- 启动次数。
- 标准完成次数。
- 超额完成次数。
- 成长最多属性。
- 解锁奖励。
- 下周建议。

文案方向：

- 强调趋势。
- 不评价人格。
- 失败只作为调整依据。

## 14. UI 文案风格

文案应该短、温柔、具体。

推荐：

- 今天也照顾一点点。
- 庭院收到了新的阳光。
- 小树又长高了一点。
- 保住节奏也是胜利。
- 今天已经很好地开始了。

避免：

- 你失败了。
- 今日未达标。
- 连续中断。
- 任务失败。
- 惩罚。

## 15. 第一版优先级

P0：

- 登录
- 今日任务
- 任务打卡
- 奖励计算
- 资源和等级
- 庭院主视觉基础版

P1：

- 任务库
- 新建和编辑任务
- 日历
- 修改密码
- 简单成就

P2：

- 装饰商店
- 周结算
- 低能量模式优化
- 更精致的动效
